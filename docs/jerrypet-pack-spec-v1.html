JerryPet 桌宠动作包格式规范 v1

JERRY.DEV 虚拟桌宠 · 待机动作 / 帧动画 / 带字图片气泡 / 触发事件 / 词库回复
格式标识：jerry-pet-pack/v1　|　配置文件：data/pet_packs.json　|　维护入口：后台 → ⚙ 发布设置 → 🐾 桌宠

给 AI 执行者的话：你只允许输出符合本规范的 JSON（必要时附素材命名清单），不要输出其他代码。所有字段名、枚举值必须与本文档逐字一致；拿不准的字段一律省略，由引擎使用默认值。

1. 它是怎么工作的

  • 桌宠出现在博客列表页和文章页，引擎文件为 assets/pet.js，启动时拉取 /data/pet_packs.json。
  • 动作包就是一份 JSON：若干 动作 actions（帧动画 + 气泡 + 触发条件）、事件 events（在特定时机执行动作/气泡/代码）、词库 replies（聊天关键词回复）。
  • 素材（透明 PNG 帧图、带字气泡图）上传到 images/pet/，在 JSON 里用 /images/pet/文件名.png 绝对路径引用。
  • 后台「🐾 桌宠」页粘贴 JSON → 保存即生效（刷新页面可见）；点「🚀 同步 Blog」后随仓库上线。

2. 顶层结构

{
  "format": "jerry-pet-pack/v1",   // 必填，固定值
  "settings": { "aiChat": false },       // 可选。true=聊天走大模型（需后台配 AI Key）
  "packs": [                          // 必填，动作包数组，可放多个包
    {
      "id": "pack-demo",              // 必填，包唯一 id（英文/数字/横线）
      "name": "示例动作包",
      "enabled": true,                 // 可选，false 则整包停用
      "actions": [ ... ],             // 动作，见第 3 节
      "events":  [ ... ],             // 事件，见第 5 节
      "replies": [ ... ]              // 聊天词库，见第 6 节
    }
  ]
}

3. 动作 action 字段

字段类型必填说明
id字符串必填动作唯一 id，全局不能重复，如 idle-sleep。events/replies 用它引用动作。
name字符串可选人类可读名称，仅后台查看用。
frames字符串数组必填帧图路径，按顺序播放，如 ["/images/pet/sleep1.png","/images/pet/sleep2.png"]。1 张=静态姿势；2 张以上=逐帧动画。
frameInterval数字(毫秒)可选每帧停留时长，默认 300。吃饭/说话类 200–400，缓慢呼吸类 600–1000。
loop布尔可选是否多轮循环。默认 false（帧播一遍）。
loops数字可选loop:true 时的循环轮数，默认 2。
holdLast布尔可选播完后停在最后一帧（默认恢复待机姿势）。
duration数字(毫秒)可选仅单帧动作有效：姿势保持时长，默认 1600。
bubble对象可选动作同时弹出的气泡，见第 4 节。
trigger对象自动触发时必填触发条件，见下。被 events/replies 手动调用的动作可省略。

3.1 trigger.kind 触发类型

kind含义支持参数
idle待机随机 角色空闲时由引擎按概率/权重随机播放chance 每次待机抽中概率 0–1（默认 0.1）；weight 权重（默认 1，越大越常出现）；minGap 距上次动作至少间隔毫秒；after 页面打开后多少毫秒才允许；timeRange 时间段
click点击身体 单击角色身体（拖拽不会误触发）—
headClick摸头 点击头部感应区—
load入场 页面加载后播放一次（欢迎动作）delay 延迟毫秒，默认 1200
longIdle无人理会 用户多久没动鼠标/键盘后播放一次after 毫秒，默认 60000（1 分钟）
timeRange 写法：[23, 7] 表示 23:00–次日 7:00（支持跨午夜）；[9, 18] 表示白天。省略 = 全天。
待机动作密度建议：每个 idle 动作给 minGap ≥ 20 秒、chance 0.05–0.15，避免角色一直动。引擎每 4–7 秒抽一次。

4. 气泡 bubble（文字 / 带字图片）

4.1 打字机文字气泡

"bubble": { "text": "Zzz…睡着了", "typed": true, "duration": 2600 }
  • text 气泡文字（建议 ≤ 24 个字，太长气泡会很高）；
  • typed 默认 true（逐字打出），设 false 直接整句显示；
  • duration 停留毫秒，默认 2600。

4.2 带字图片气泡（图片上自己带文字）

"bubble": { "image": "/images/pet/bubbles/hello.png", "duration": 3200 }
  • 把做好的带字图片上传到 images/pet/（建议放 bubbles/ 子目录），建议尺寸宽 360–420px、透明或白底 PNG；
  • 图片最大显示宽 210px，文字别贴边。

5. 事件 events

动作的 trigger 覆盖不了的复杂时机用事件。事件在指定时机触发，可播放动作、弹气泡、或执行一小段代码。

字段说明
id 必填事件唯一 id。
on 必填load 入场 · click 点身体 · headClick 摸头 · scrollDepth 阅读深度 · timeRange 时间段 · userSend 用户发消息。
action要播放的动作 id。
bubble要弹出的气泡（同第 4 节）。
depth仅 scrollDepth：0–1，如 0.95 = 看到文章 95%。
timeRange仅 timeRange：时间段，每小时最多触发一次。
match仅 userSend：关键词数组，命中才触发（与 replies 二选一即可）。
code可选 JS 代码字符串，见第 7 节 API。
// 例：读者把文章看到 95% 时，角色鼓掌+气泡
{
  "id": "read-to-end",
  "on": "scrollDepth",
  "depth": 0.95,
  "action": "cheer",
  "bubble": { "text": "居然看完了！给你点赞👍" }
}

6. 聊天词库 replies

{
  "match": ["再见", "拜拜", "byebye"],   // 命中任一关键词（不区分大小写、包含即可）
  "text":  "下次再来玩呀~",   // 必填，回复文字（打字机）
  "action": "wave-bye",       // 可选，同时播放动作
  "bubble": { ... }                  // 可选，一般给 text 即可，二选一
}

回复优先级：词库 replies → 大模型（settings.aiChat=true 且本地配了 Key）→ 内置兜底闲聊。线上静态站没有本地服务，AI 与写接口不可用，会自动降级到词库。

7. 事件代码可用 API（events[].code）

代码运行在受限作用域，只注入 pet（JerryPet）和 ctx（事件上下文），不要访问 DOM 以外的敏感能力。

调用作用
pet.play('动作id')播放指定动作（返回 Promise）
pet.bubble('文字')弹文字气泡
pet.bubble({image:'/images/pet/x.png', duration:3000})弹带字图片气泡
pet.setImg('/images/pet/x.png')直接切换角色图片（慎用，不会自动恢复）
pet.react('/images/pet/x.png', 1500)临时反应姿势，毫秒后自动恢复待机
pet.fire('事件名', {参数})手动广播事件
ctx事件上下文：scrollDepth 时 ctx.depth；userSend 时 ctx.text / ctx.reply
// 例：深夜时段弹图片气泡
{ "id":"late-night", "on":"timeRange", "timeRange":[23,6],
  "code": "pet.bubble({image:'/images/pet/bubbles/late.png', duration:4000});" }

8. 完整示例：一个「睡觉 + 早安」补充包

{
  "format": "jerry-pet-pack/v1",
  "settings": { "aiChat": false },
  "packs": [{
    "id": "sleep-pack",
    "name": "睡觉与早安",
    "enabled": true,
    "actions": [
      {
        "id": "sleep",
        "name": "深夜睡觉",
        "frames": ["/images/pet/sleep1.png", "/images/pet/sleep2.png", "/images/pet/sleep3.png"],
        "frameInterval": 700,
        "loop": true,
        "loops": 3,
        "bubble": { "text": "Zzz…深夜了，早点睡哦", "duration": 3200 },
        "trigger": { "kind": "idle", "chance": 0.2, "minGap": 60000, "timeRange": [23, 6] }
      },
      {
        "id": "morning",
        "name": "早安入场",
        "frames": ["/images/pet/morning1.png", "/images/pet/morning2.png"],
        "frameInterval": 250,
        "bubble": { "image": "/images/pet/bubbles/good-morning.png", "duration": 3500 },
        "trigger": { "kind": "load", "delay": 1500, "timeRange": [6, 11] }
      }
    ],
    "replies": [
      { "match": ["晚安", "睡觉"], "text": "晚安好梦，明天见~", "action": "sleep" }
    ]
  }]
}
trigger 里的 timeRange 目前仅 idle 与 load 动作生效；其他触发类型要按时段出现，请改用 events 的 timeRange。

9. 素材规范

  • 格式：透明背景 PNG（WebP 也可）；不要 JPG（白底方块）。
  • 尺寸：角色帧建议高 300–400px，同一动作所有帧画布宽高必须完全一致、角色脚底对齐同一基线，否则播放会跳动。
  • 帧数/帧率：循环待机动作 2–6 帧即可；帧越多文件越大。帧间隔参考：慢呼吸 700–1000ms、普通动作 300–400ms、活泼动作 150–220ms。
  • 命名：动作名+序号，如 sleep1.png / sleep2.png，全小写英文/数字/横线；气泡图放 bubbles/ 子目录。
  • 上传：后台「🐾 桌宠」→「上传动作帧图 / 上传带字气泡图」，上传后点「📋 复制路径」粘进 JSON。

10. 校验与排错

  • 后台保存时会自动校验：format、packs 数组、每个动作的 id 与 frames 类型；语法错误会直接报在页面上。
  • 浏览器 F12 控制台：[JerryPet] event code error = 某条 code 写错（不影响其他动作）；/data/pet_packs.json 404 = 文件还没保存过。
  • 动作不出现：检查 enabled 是否 true、minGap 是否太长、chance 是否太小、帧路径是否 404（F12 → Network 看图片状态）。
  • 新增/修改后：刷新博客或文章页生效；要让线上访客看到，需点「🚀 同步 Blog」发布。
