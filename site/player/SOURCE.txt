This directory is a prebuilt web bundle of Folia. The build used:
  VITE_NETEASE_API_BASE=/api/netease npx vite build --base=/player/

Folia is copyright its contributors. Source code and license:
https://github.com/chthollyphile/folia-major

Local modification: site/player/index.html pre-seeds Folia's one-time 0.7.21 onboarding flags
so the player opens directly; it does not alter Folia's source or subsequent user choices.

Local modifications: /player/index.html sets viewport-fit=cover, mobile 100dvh/backdrop-blur
performance overrides, mobile visualizer defaults, skips onboarding, and unregisters Folia's
service worker to avoid a 15MB mobile precache. Folia's source is otherwise unmodified except for the patches listed in PATCHES.md.

Additional local adaptation: /player/index.html injects a mobile persistent transport bar
(play/pause, seek, cover/title, panel button), a desktop persistent play/pause control, and an
automatic low-performance fallback (network type/device memory + runtime FPS) that switches to
Folia's lightweight visualizer mode once.

Bravais mobile: the seam is pinned to the left edge, its navigation is always visible with
larger touch targets, and a subtle grid icon at the bottom switches to the classic Grid library.
Mobile Bravais also drops the grain overlay and seam shadow for smoother scrolling.

Branding: splash now starts with callmiruko.cc, and the Bravais mobile rail contains site-page links.
The desktop/mobile player transport uses Folia's real next/previous transport handlers.
